## 🎯 **Recommended Upload Option**

### **Option 2: Images + Datasets** (Recommended)

**What it uploads:**
- ✅ Images (30GB) - Saves 3-4 hours download time
- ✅ Datasets (1GB) - train1.csv, train2.csv, test1.csv, test2.csv

**What it skips:**

- ❌ Try3 models - Not needed (Try4 retrains from scratch)

**Time:**
- Upload: ~1-2 hours
- Download: ~1-2 hours
- **Total transfer: ~2-4 hours**

**Cost:**
- Google Drive: FREE (have 1TB)
- Compute: $0 (no running instances during transfer)

## 📊 **What Try4 Needs**

### **Required (Must Transfer):**
```
try2/images/                      ~30GB  ← TRANSFER
├── train/                        75K images
└── test/                         75K images

try2/dataset/                     ~1GB   ← TRANSFER  
├── train1.csv
├── train2.csv
├── test1.csv
└── test2.csv
```

### **Generated by Try4 (Don't Transfer):**
```
try4/outputs/embeddings/          ~10GB  ← REGENERATE
├── deberta_train_embeddings.csv  (NEW: DeBERTa-v3-large)
├── deberta_test_embeddings.csv
├── clip_train_embeddings.csv     (NEW: CLIP ViT-Large)
└── clip_test_embeddings.csv

try4/outputs/features/            ~1GB   ← REGENERATE
├── tabular_train_features.csv
└── tabular_test_features.csv

try4/outputs/models/              ~10GB  ← REGENERATE
└── lightgbm_fold_*.txt           (5 models)
```

**Why regenerate?**
- Try4 uses **different models** than Try3
  - Text: DeBERTa-v3-large (vs DistilBERT in Try3)
  - Image: CLIP ViT-Large (vs ResNet50 in Try3)
- Try3 embeddings are **incompatible** with Try4
- Fresh embeddings ensure **optimal performance**

## 🎓 **Step-by-Step Walkthrough**

### **Phase 1: On OLD Instance (1-2 hours)**

```bash
# 1. Navigate to try4
cd ~/Smart-Product-Pricing-Challenge/try4

# 2. Check what you have
du -sh ../try2/images

# 6. SAVE THE BUCKET NAME!
#    Example output:
#    📋 Bucket path: gdrive:hackathon-try4-20251013/
#    ^^^^^^^^^^^^^^^^^^^^^^^^ COPY THIS!

# 7. Verify upload succeeded

# 8. Optional: Shut down old instance to save costs
```

### **Phase 2: On NEW Instance (4-6 hours)**

```bash

#                         Use YOUR bucket name from step 6 above

# 6. Verify system

# 7. Run Try4 pipeline

#   - Extract tabular features (~10 min)
```

## 🔍 **Troubleshooting**

### **"rclone: command not found"**
```bash
curl https://rclone.org/install.sh | sudo bash
```

### **"gdrive remote not found"**
```bash
rclone config
# Choose: n (new remote)
# Name: gdrive
# Storage: drive
# Follow browser authentication
```

### **"Bucket not found on new instance"**
```bash
# Make sure using SAME Google account
rclone config show
# Should show gdrive with correct credentials

# List available buckets
rclone lsd gdrive: | grep hackathon
```

### **"Images download is slow"**
```bash
# Check connection
rclone check gdrive:BUCKET/images/ try2/images/ --one-way

# Resume interrupted download
./download_from_gdrive.sh BUCKET_NAME
# Will automatically resume
```

### **"Out of disk space"**
```bash
# Check space
df -h
# Need at least 50GB free

# Clean up if needed
rm -rf try3/outputs/*  # Delete Try3 outputs
```
